# Mineradio

![Mineradio_Заставка в темной теме](./docs/assets/readme/cinema-beat-smoke.png)

Mineradio — это Windows-музыкальный плеер для рабочего стола с эффектом погружения. Поиск и воспроизведение, лирическая сцена, визуализация частиц, трёхмерный список воспроизведения и полноценный режим рабочего стола объединяются, создавая личное музыкальное пространство, напоминающее живое выступление.

## Что делать, если загрузка или установка заблокирована?

Поскольку это нишевое десктопное приложение на базе Electron, неподписанный установщик может иногда вызывать предупреждения о рисках со стороны браузеров, Защитника Windows или фильтра SmartScreen. Пожалуйста, убедитесь, что установщик загружен по указанной выше ссылке на облачное хранилище или с официальной страницы релизов на GitHub, а имя файла — `Mineradio-2.1.0-Setup.exe`.

1. Если панель загрузки браузера указывает на наличие риска, откройте список загрузок, нажмите на значок `...` (три точки) справа от загружаемого файла и выберите «Сохранить», «Всё равно сохранить» или «Показать еще», чтобы продолжить сохранение файла.
2. Когда Windows SmartScreen показывает синее окно блокировки, нажмите `Дополнительная информация`, затем нажмите `Выполнить в любом случае`.
3. Если ваш антивирус однозначно помечает файл как «троян» или объект с высоким уровнем риска либо уже поместил его в карантин, не пытайтесь запустить его принудительно. Удалите файл и скачайте его заново по ссылке на облачное хранилище, приведенной выше; если проблема сохранится, сделайте скриншот и сообщите об этом автору.

## Ключевые особенности

- Главная страница содержит ежедневные рекомендации, рекомендации платформы, «продолжить слушать», музыкальный портрет и вход в мои плейлисты
- Полный режим рабочего стола сохраняет плеер, главную страницу, плейлисты и взаимодействие с рабочим столом
- Поддержка локального MP4 и визуального контента Wallpaper Engine
- После начала воспроизведения переключается на визуальное состояние Emily / по умолчанию, лирическая сцена и сцена частиц работают синхронно
- Кинематографическая визуальная система, основанная на ритме
- Специальный визуальный режим для длинных подкастов и DJ-треков
- Лирическая сцена, пользовательские тексты песен, позиция текста и управление визуализацией
- Загрузка и обрезка собственной обложки альбома
- Вызов 3D-полки плейлистов правой кнопкой мыши, поддержка просмотра очереди плейлистов
- Интеграция с учётной записью NetEase Cloud Music, поиском, плейлистами, подкастами и т.д.
- Дополнительная интеграция с QQ Music: поиск, статус входа и источники аудио
- Обнаружение обновлений GitHub Releases и ссылка для загрузки
- При первом запуске встроен визуальный пользовательский архив «Тест по умолчанию», параметры визуализации по умолчанию в приложении совпадают с этим архивом

## Инструкция по использованию

Пользователи Windows могут загрузить установочный пакет с Quark Drive, Baidu Cloud, Lanzou Cloud или GitHub Release, перечисленных на этой странице.

Официальное распространение основано на `Mineradio-2.1.0-Setup.exe`, не рекомендуется напрямую использовать каталог `win-unpacked`. Установщик создаст ярлык на рабочем столе.

Пользователи, уже установившие старую версию, могут просто запустить `Mineradio-2.1.0-Setup.exe` для обновления. Функция обновления в приложении только открывает страницу загрузки в браузере и не загружает и не применяет патчи внутри клиента.

## Запуск для разработки

```bash
npm install
npm start
npm run build:win
```

Вход в настольную версию загружается локальным сервисом из основного процесса Electron. `npm run build:win` создаст установщик Windows NSIS, результат будет в каталоге `dist/`.

## Механизм обновления

Mineradio запрашивает последнюю версию с GitHub Releases. Когда удалённая версия выше локальной, раздел обновления в приложении отображает содержимое релиза и открывает дополнительные сетевые диски через системный браузер; даже если к релизу прикреплён полный установочный пакет, клиент версии `2.0.3+` не будет читать, загружать, кэшировать или применять этот файл или патч.

Для локальной проверки цепочки обновлений можно указать `MINERADIO_UPDATE_MANIFEST` на локальный manifest JSON или HTTP-адрес, чтобы имитировать онлайн-релиз.
